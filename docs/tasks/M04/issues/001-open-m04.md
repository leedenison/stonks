## Scope

Massive and EODHD join OpenFIGI as identity datasources. Resolution chooses among the
answers of three real providers. A key whose fetch served candidates but associated
nothing keeps those candidates, and the user can confirm one.

## Open questions

- The default precedence of OpenFIGI, Massive and EODHD. Precedence alone picks the
  winner among datasource answers, so it decides which provider supplies an instrument's
  metadata.
- For each provider:
  - which endpoints answer for identity;
  - which identifier types and domains it accepts and returns;
  - which identifier it sends for each stated type;
  - whether it needs an identifier type the system lacks.
- How each provider's venue codes map to an operating MIC, such as EODHD's exchange
  codes. Whether the mapping is a reference table like the MIC table, and how it is
  generated.
- How each provider states a composite listing that spans several venues.
- Which venues and asset classes each provider covers. Massive covers US equities.
  EODHD's coverage, thought to be North America and Europe, is to be checked against
  its documentation.
- How a provider is kept to its coverage, so it answers only for the venues and asset
  classes it covers. The answer depends on what is known when the provider is asked:
  - the stated key names a venue, inside or outside the provider's coverage;
  - the stated key carries only a stable identifier, so the venue is unknown until a
    provider answers;
  - the stated key carries a bare ticker with no venue;
  - a higher precedence datasource answered with a listing inside or outside the
    provider's coverage, or did not answer.

  Every enabled datasource is asked concurrently, so a provider is asked before any
  higher precedence answer exists. Coverage may decide whether the provider is asked,
  which of its candidates are dropped, or both. Which of these applies is open. Where the
  provider does not serve a key, it records no coverage for the key.
- Each provider's quota and rate limit, and which of its errors are temporary.
- Whether the e2e vcrproxy serves three upstreams from one instance or runs one instance
  per provider.
- The open questions of the instrument resolution note that a second real source now
  exercises:
  - whether a candidate counts as independent corroboration when the ranking raised it
    for agreeing with a higher precedence answer;
  - what happens when every candidate from every datasource contradicts the stated data;
  - whether a datasource is barred from an instrument after its answer overlapped the
    instrument only on a MIC-derived identifier.
