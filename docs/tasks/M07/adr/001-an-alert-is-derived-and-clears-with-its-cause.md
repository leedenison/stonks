# An alert is derived and clears with its cause

The alerts page lists what needs an administrator across every surface. Alerts are
not stored. Each kind of alert is a query over rows that already exist: open blocks,
failed runs, uncleared findings, undecided corporate actions, and the tickers and gaps
that the coverage derivation reports. An alert disappears when an administrator settles
its cause. A stored alert would drift from the rows it describes and would need a
lifecycle of its own.
