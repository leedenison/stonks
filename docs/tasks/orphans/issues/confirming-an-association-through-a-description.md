## Scope

An association made through a broker description is provisional, since a broker may
rename a line and no source reports it. An administrator confirms one association, or
confirms the associations of every key made through one description in a single step.

## Design

Nothing settled. Validity is a column of the stated key, written by resolution, and
nothing writes it after that.
