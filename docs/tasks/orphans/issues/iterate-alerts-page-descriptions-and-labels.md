## Scope

A pass with the user over the copy of the alerts page on real data: the kind names on
the tiles and chips, the explanation behind each group's info icon, the detail line of
each kind, the button labels, and the titles, summaries and descriptions of the Runs
card. The pass records what each label should say, changes the page to match, and files
under D-UI any fault in the page's shape, as opposed to its copy.

## Motivation

The copy is judged after the page has been used for a while, so that the pass works
from what an administrator actually needs to read.
