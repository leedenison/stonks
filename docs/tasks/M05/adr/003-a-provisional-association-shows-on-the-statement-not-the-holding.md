# A provisional association shows on the statement, not the holding

A transaction of a dated key is confirmed, provisional or unresolved by where its date
falls in its ticker's validity. A transaction of a fixed association is provisional when
the association used an unstable identifier, such as a broker description or an option
symbol. A transaction of an instrument the user chose is confirmed.

The statement details page marks each transaction. The holdings page shows a holding the
same way, whether the transactions beneath it are confirmed or provisional.

A user reviews a statement to check how its lines were understood, so the mark belongs
there, and it belongs on the transaction because two transactions of one key can differ.
On holdings, most associations would be provisional until coverage grows, and the mark
would be noise.
