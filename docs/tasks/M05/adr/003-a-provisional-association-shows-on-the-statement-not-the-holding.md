# A provisional association shows on the statement, not the holding

An association is provisional when it rests on validity outside identifier event coverage.

The statement details page marks each key whose association is provisional. The holdings
page shows a holding the same way, whether its associations are confirmed or provisional.

A user reviews a statement to check how its lines were understood, so the mark belongs
there. On holdings, most associations would be provisional until coverage grows, and the
mark would be noise.
