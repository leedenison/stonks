# A user's choice pins an unassociated key

A user's choice of a candidate for a key with no association gives the key a fixed
association with that instrument, with the user as arbiter. It holds for every transaction
of the key, whatever their dates. An event on the value the key states does not touch it.

A key with an association, fixed or dated, refuses a choice. A transaction of a dated key
that is unresolved on its date has one way out in this milestone: an administrator attests
the value on that day.

A choice over a run of a dated key's transactions, a choice of listing, a venue supplied
for a bare ticker, and a search that creates an instrument no datasource serves are
deferred. They rest on the key being the user's, which this milestone builds, and on
nothing else in it.
