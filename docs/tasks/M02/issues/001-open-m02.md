## Scope

Transaction ingestion from one broker's upload, resolved against the database only, and
the holdings derived from the transaction log. No datasource is called, so every
instrument resolves to its broker description and quantities are shown raw.

## Open questions

Runs, issue [004](004-runs.md):

- The states a run passes through, and what an upload interrupted mid-way leaves behind.
- Whether more than one run of a user proceeds at once.

Neutral format, issue [005](005-neutral-format-and-first-marshaller.md):

- Which broker and channel comes first, and which of its conventions the format must
  express: the "as at" date, several legs on one line, stated splits.
- Whether correlations are carried and stored now, or left out until events are grouped.

Ingestion, issue [006](006-upload-ingestion.md):

- What makes a row invalid.
